# Lab 03 — Trả lời thảo luận

- Merge base là tổ tiên chung gần nhất của hai nhánh. Git so sánh mỗi nhánh
  với mốc này để tính phần thay đổi khi merge.
- `master` và `release/*` là lịch sử dùng chung. `revert` tạo commit đảo ngược
  có thể truy vết; `reset` viết lại lịch sử và có thể làm mất commit đã chia sẻ.
- Với lỗi giới hạn giỏ hàng, test thất bại ở điều kiện cũ `>` và đạt sau khi
  sửa thành `>=`. Điều đó chứng minh test thực sự bắt được lỗi.
